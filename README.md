# CRUD-Clients
Java Spring Professional Course Challenge - CRUD-Clients

# DESCRIPTION
This is a RESTful API built with Spring Boot that implements a CRUD system to manage client resources. This project applies data validation and global exception handling.

# USED TECHNOLOGIES
- Java 21
- Spring Boot 4
- Spring Web
- Spring Data JPA
- Validation
- Hibernate
- H2 Database
- Maven

# FEATURES
- Create Clients
- Read Clients
- Read Paginated client list
- Update Clients
- Delete Clients

# API ENDPOINTS
GET /clients
GET /clients/{id}
GET /clients?queryparams
POST /clients
PUT /clients/{id}
DELETE /clients/{id}
